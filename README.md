# Procurement-Vendor-Analysis-Dashboard

## Project Overview

This project is an end-to-end Procurement & Vendor Analysis Dashboard developed using Excel Power Query, MySQL, and Power BI.

The objective of this project is to analyze procurement operations, vendor performance, department spending, payment status, and delivery efficiency to support business decision-making through interactive dashboards and analytical reporting.

This project demonstrates the complete data analytics workflow including:
- Data Cleaning
- Data Transformation
- SQL Analysis
- Business Intelligence Dashboarding
- KPI Reporting
- Data Visualization

---

- Excel

# Project Workflow

## 1. Data Cleaning using Power Query
Performed ETL operations on raw procurement data:
- Removed duplicate records
- Handled missing values
- Changed incorrect data types
- Created Month, Quarter, and Year columns
- Cleaned text formatting
- Created delivery performance metrics

---

## 2. SQL Analysis using MySQL
Imported cleaned dataset into MySQL and performed analytical queries such as:
- Vendor-wise procurement spending
- Department-wise spending analysis
- Monthly procurement trends
- Delayed order analysis
- Payment status analysis
- Top vendor identification

---

## 3. Power BI Dashboard Development
Created an interactive dashboard containing:
- KPI Cards
- Vendor Spending Analysis
- Monthly Procurement Trends
- Category-wise Procurement Distribution
- Department Spending Analysis
- Payment Status Tracking
- Interactive Slicers and Filters
